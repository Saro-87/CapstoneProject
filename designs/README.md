# Stratus frontend design preview

Open `index.html` in a browser. No installation or server needed.

This local styling prototype uses simulated October 2026 data, including illustrative GCP costs. It does not connect to the Python connectors or any cloud account.

Try the cloud filters, service search, dark mode button, and CSV export. Sidebar links jump to the corresponding dashboard sections. The layout adapts to mobile screens.

Files: `index.html` (layout), `style.css` (styling), `app.js` (sample data and interactions).

Open designs.html to compare all four directions. New designs: Midnight (dark operations), Solstice (warm editorial), and Prism (bold colorful). They share app.js and style.css, with layout overrides in variants.css.
